Esports Highlight Reels

Privacy Policy

Effective September 4, 2026 Third-party user data collected none

This tool has one user — its operator — and no public sign-up. Nothing below describes data collected from TikTok users, viewers, or anyone besides the operator.

1

What the tool touches

DataWhere it comes from / goes
Public YouTube tournament videoDownloaded temporarily to render a clip; not personal data
Clip audio & video segmentsSent to Google's Gemini API to identify highlights and pick a crop
Video ID, clip timestamps, title, publish statusLogged to the operator's own private Google Sheet, for de-duplication only
Platform access tokens (YouTube, Facebook, TikTok, Instagram)Stored only in a local, git-ignored file on the operator's machine
2

No data from other people

The tool does not create accounts for anyone, does not accept input from the public, and does not collect, store, or process personal data belonging to any TikTok user, viewer, or third party. The only TikTok account it ever posts to, or reads engagement from, is the operator's own.

3

Where things are stored

Rendered video files live temporarily on the operator's own machine and are not uploaded anywhere except the four publishing platforms listed above. Operational records (which VOD was processed, what was published, and when) live in a Google Sheet owned by the operator. Nothing is stored on any server operated by a third party beyond the AI and publishing services each clip necessarily passes through.

4

Sharing

Data is shared only with the services required to run the pipeline itself: Google's Gemini API (highlight detection and crop analysis), the YouTube Data API (checking for new tournament uploads), and the publishing APIs of YouTube, Facebook, TikTok, and Instagram (to post the approved clip). Nothing is sold, and nothing is shared for advertising or analytics purposes.

5

Retention & deletion

Rendered clips are deleted from local storage once published or rejected. The operator can delete the Google Sheet's history at any time; doing so only affects duplicate-detection on already-processed videos, nothing else.

Questions about this integration — including for TikTok's app review — go to esportshighlightbot@gmail.com.
